## My Learning Journey

Throughout this course, I explored how Deep Learning can
be used to solve problems involving data, images, and
other complex patterns.

My work focuses not only on building models, but also on
understanding:

- How neural networks learn
- How data is prepared for deep learning
- How models are trained and optimized
- How model performance is evaluated
- How different architectures affect results
- How experiments can be interpreted and improved
