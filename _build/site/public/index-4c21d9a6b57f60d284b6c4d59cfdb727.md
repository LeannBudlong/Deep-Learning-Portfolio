# Laboratory Activities

The laboratory activities in this section document my hands-on experience applying Deep Learning concepts.

Each laboratory contains the implementation, results, analysis, and observations developed throughout the course.

## Labs

```{list-table}
:header-rows: 1

* - Lab
  - Topic
  - Description

* - 01
  - Introduction to Deep Learning
  - Explores the basic concepts and foundations of Deep Learning.

* - 02
  - Forward Propagation
  - Performs a single forward pass through a neural network and computes the resulting prediction and error.

* - 03
  - Forward and Backward Propagation
  - Applies forward propagation, backpropagation, gradient computation, and parameter updates in Python.

* - 04
  - Linear Regression in PyTorch
  - Trains and evaluates a linear regression model using PyTorch, MSE Loss, SGD, and mini-batch training.

* - 05
  - PyTorch Tensor Operations
  - Performs basic tensor creation, reshaping, indexing, data type conversion, and matrix multiplication.

* - 06
  - CNN Architecture Implementation
  - Converts a given Convolutional Neural Network architecture diagram into a working PyTorch model and verifies its tensor dimensions.
